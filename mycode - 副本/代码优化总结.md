### 6. **LoginInterceptor 优化** 🟡 中优先级

**问题：**
- ❌ 直接写入响应字符串（应该统一格式）
- ❌ 缺少日志记录
- ❌ 没有使用常量

**建议修改：**
```java
// 添加日志
@Slf4j
@Component
public class LoginInterceptor implements HandlerInterceptor {
    
    @Override
    public boolean preHandle(...) {
        String token = request.getHeader("Authorization");
        
        if (token == null) {
            log.warn("请求缺少Token: {}", request.getRequestURI());
            writeErrorResponse(response, 401, "未提供认证Token");
            return false;
        }
        
        try {
            // ...验证逻辑
        } catch (Exception e) {
            log.error("Token验证失败: {}, URI: {}", e.getMessage(), request.getRequestURI());
            writeErrorResponse(response, 401, "Token无效");
            return false;
        }
    }
    
    private void writeErrorResponse(HttpServletResponse response, int code, String message) {
        response.setStatus(code);
        response.setContentType("application/json;charset=UTF-8");
        response.getWriter().write(
            String.format("{\"code\":%d,\"message\":\"%s\"}", code, message)
        );
    }
}
```
