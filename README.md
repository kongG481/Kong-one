The system is built on a B/S architecture, using MySQL database for data storage and implementing business logic through JSP/Servlet or SSM framework. It supports teacher registration, login, personal information maintenance, and basic management functions such as account enabling/disabling and role assignment by administrators. In terms of question management, the system provides complete CRUD operations: teachers can select question types (single-choice, multiple-choice, fill-in-the-blank, and essay questions) via dropdown menus, fill in question content, subject category, difficulty level, suggested time, and question source. For multiple-choice questions, teachers can dynamically add A/B/C/D options and mark the correct ones; for fill-in-the-blank questions, they can enter answers (supporting multiple correct answers for a single blank); for essay questions, they can input reference answers and scoring criteria. During the submission process, the system automatically checks whether the question content already exists in the question bank — if a duplicate is found, the system alerts the teacher and prevents duplicate submission. Teachers can also edit and soft-delete their own questions (deleted questions go to the recycle bin and can be restored or permanently removed), with each modification retaining a previous version in the history table for traceability and rollback. For query and export functions, the system supports multi-condition combined searches by question type, subject, difficulty level, creator, time range, and keyword fuzzy search. Search results are displayed in paginated lists or card views, and teachers can select desired questions for one-click export to Word documents (with question numbers, options, and answers) or Excel spreadsheets (one question per row with columns for each field), with all export operations automatically logged. The system also includes a built-in duplicate detection mechanism: when teachers submit a new question, the system compares question text for exact duplication and provides warnings if duplicates are found. The statistical analysis module uses charts (bar charts, pie charts, line charts) to visually display total question count, distribution by question type, quantity per subject, difficulty distribution, and rankings of questions created by each teacher, helping teachers and administrators fully understand the overall status and quality of the question bank. The entire system features a clean and intuitive interface with clear permission control — regular teachers can only manage their own questions while administrators have full management authority, and all critical operations (login, insert, update, delete) are recorded in the log table for audit and tracking purposes.）
